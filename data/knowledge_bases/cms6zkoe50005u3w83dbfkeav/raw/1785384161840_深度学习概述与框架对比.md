# 深度学习概述与框架对比

## 深度学习 vs 传统机器学习

| 对比维度 | 传统机器学习 | 深度学习 |
|----------|-------------|----------|
| 特征提取 | 手动特征工程 | 自动学习特征 |
| 数据需求 | 较少 | 大量 |
| 计算资源 | CPU 即可 | GPU/TPU |
| 性能 scaling | 增加数据收益递减 | 数据越多性能越好 |
| 可解释性 | 较好 | 较差（黑盒） |

## 主要框架对比

| 框架 | 发布者 | 特点 |
|------|--------|------|
| TensorFlow | Google | 生产部署强，TF Serving |
| PyTorch | Meta | 易调试，研究首选 |
| Keras | 开源 | 高层 API，适合快速原型 |
| JAX | Google | 函数式，自动微分，高性能 |
| PaddlePaddle | 百度 | 中文生态好 |
| MindSpore | 华为 | 昇腾芯片适配 |

## 核心概念

- **张量（Tensor）** — 多维数组，深度学习的基本数据单位
- **自动微分** — 自动计算梯度，框架自动完成反向传播
- **GPU 加速** — CUDA + cuDNN，并行计算大幅提速

## 硬件选择

```
CPU: 数据加载、预处理
GPU: 模型训练、推理（NVIDIA CUDA）
TPU: Google 专用，大规模训练
NPU: 华为昇腾，端侧推理
```

## 学习路线

1. Python 基础 → 2. 线性代数/微积分 → 3. 机器学习基础 → 4. 深度学习框架 → 5. 经典模型 → 6. 实战项目
