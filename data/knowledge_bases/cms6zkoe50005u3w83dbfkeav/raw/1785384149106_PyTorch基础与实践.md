# PyTorch 基础与实践

## 张量基础

```python
import torch

x = torch.tensor([[1, 2], [3, 4]])
x = torch.zeros(3, 4)
x = torch.randn(3, 3)           # 正态分布
x = torch.arange(10)

# GPU 加速
device = "cuda" if torch.cuda.is_available() else "cpu"
x = x.to(device)
```

## 自动求导 Autograd

```python
x = torch.randn(3, requires_grad=True)
y = x.pow(2).sum()
y.backward()          # 自动计算梯度
print(x.grad)         # 查看梯度
```

## 构建模型

```python
import torch.nn as nn

class MLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(784, 256),
            nn.ReLU(),
            nn.Dropout(0.5),
            nn.Linear(256, 10)
        )

    def forward(self, x):
        return self.net(x)

model = MLP().to(device)
```
