# 神经网络基础与感知机

## 生物神经元 vs 人工神经元

- **生物神经元**: 树突 → 细胞体 → 轴突 → 突触
- **人工神经元**: 输入 → 加权求和 → 激活函数 → 输出

## 感知机（Perceptron）

1958 年 Frank Rosenblatt 提出，是神经网络的基础单元。

```python
import numpy as np

class Perceptron:
    def __init__(self, lr=0.01, epochs=100):
        self.lr = lr
        self.epochs = epochs

    def fit(self, X, y):
        self.weights = np.zeros(X.shape[1])
        self.bias = 0
        for _ in range(self.epochs):
            for xi, yi in zip(X, y):
                y_pred = self.predict(xi)
                error = yi - y_pred
                self.weights += self.lr * error * xi
                self.bias += self.lr * error

    def predict(self, X):
        return np.where(self.activation(X) >= 0, 1, 0)

    def activation(self, X):
        return np.dot(X, self.weights) + self.bias
```

## 感知机的局限

- 只能解决**线性可分**问题（如 AND、OR）
- 无法解决 XOR 异或问题（线性不可分）

## 多层感知机（MLP）

- 输入层 + 隐藏层 + 输出层
- 引入非线性激活函数解决 XOR 问题
- 通用逼近定理：足够宽的单隐藏层网络可逼近任意连续函数

## 网络结构

```
输入层 → [权重×输入 + 偏置 → 激活函数] → 隐藏层 → ... → 输出层
```

## 典型架构参数

| 层类型 | 作用 |
|--------|------|
| Dense/全连接 | 每个神经元连接下一层所有神经元 |
| 激活层 | 引入非线性 |
| Dropout | 随机失活，防过拟合 |
| BatchNorm | 批量归一化，加速训练 |
