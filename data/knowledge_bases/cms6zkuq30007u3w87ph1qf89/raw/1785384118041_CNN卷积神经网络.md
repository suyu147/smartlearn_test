# CNN 卷积神经网络

## 核心思想

- **局部连接** — 每个神经元只连接输入的部分区域
- **权值共享** — 同一卷积核在所有位置共享参数
- **池化下采样** — 降低维度，提取主要特征

## 基本结构

```
输入 → [Conv → ReLU → Pool] × N → Flatten → Dense → 输出
```

## 卷积层

```python
import torch.nn as nn

# 2D 卷积
conv = nn.Conv2d(
    in_channels=3,     # 输入通道数（RGB=3）
    out_channels=64,   # 输出通道数（卷积核数量）
    kernel_size=3,     # 卷积核大小 3×3
    stride=1,          # 步长
    padding=1          # 填充
)
```

## 池化层

```python
# 最大池化 2×2
pool = nn.MaxPool2d(kernel_size=2, stride=2)

# 平均池化
avg_pool = nn.AdaptiveAvgPool2d((1, 1))
```

## 经典网络架构

| 网络 | 年份 | 特点 |
|------|------|------|
| LeNet-5 | 1998 | 手写数字识别 |
| AlexNet | 2012 | 深度CNN，ReLU，Dropout |
| VGGNet | 2014 | 小卷积核堆叠 |
| GoogLeNet | 2014 | Inception模块 |
| ResNet | 2015 | 残差连接，解决退化 |
| DenseNet | 2017 | 密集连接 |
| MobileNet | 2017 | 深度可分离卷积 |

## ResNet 残差块

```python
class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super().__init__()
        self.conv1 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(channels)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(channels, channels, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(channels)

    def forward(self, x):
        residual = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += residual    # 残差连接
        return self.relu(out)
```
