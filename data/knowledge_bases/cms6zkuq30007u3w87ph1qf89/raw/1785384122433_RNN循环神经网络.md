# RNN 循环神经网络

## 核心思想

RNN 通过隐藏状态传递序列信息，适合处理时序数据。

## RNN 基本单元

```
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
y_t = W_y · h_t + b_y
```

## PyTorch 实现

```python
import torch.nn as nn

rnn = nn.RNN(
    input_size=100,    # 输入特征维度
    hidden_size=256,   # 隐藏状态维度
    num_layers=2,      # 层数
    batch_first=True
)

lstm = nn.LSTM(
    input_size=100,
    hidden_size=256,
    num_layers=2,
    batch_first=True,
    bidirectional=True  # 双向
)

gru = nn.GRU(
    input_size=100,
    hidden_size=256,
    num_layers=2,
    batch_first=True
)
```

## LSTM（长短期记忆网络）

解决 RNN 的长期依赖问题，引入门控机制。

- **遗忘门**: 决定丢弃哪些信息
- **输入门**: 决定存储哪些新信息
- **输出门**: 决定输出哪些信息

```
f_t = σ(W_f · [h_{t-1}, x_t] + b_f)    # 遗忘门
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)    # 输入门
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)    # 输出门
c_t = f_t * c_{t-1} + i_t * tanh(W_c · [h_{t-1}, x_t] + b_c)
h_t = o_t * tanh(c_t)
```

## GRU（门控循环单元）

LSTM 的简化版，参数更少，训练更快。

- 重置门 + 更新门（比 LSTM 少一个门）

## RNN 变体总结

| 模型 | 参数量 | 长期依赖 | 训练速度 |
|------|--------|----------|----------|
| RNN | 少 | ❌ 差 | 快 |
| LSTM | 多 | ✅ 好 | 慢 |
| GRU | 中 | ✅ 好 | 中 |

## 应用场景

- 机器翻译（Seq2Seq + Attention）
- 情感分析
- 语音识别
- 时间序列预测
- 文本生成

## Transformer 的冲击

目前 Transformer（BERT, GPT）在大多数序列任务上已取代 RNN，但在小规模时序数据上 RNN/LSTM 仍有优势。
