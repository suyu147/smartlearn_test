# 激活函数与损失函数

## 激活函数

引入非线性，使网络能拟合复杂函数。

### Sigmoid
```python
import numpy as np
def sigmoid(x):
    return 1 / (1 + np.exp(-x))
```
- 输出范围 (0, 1)
- 缺点：梯度饱和、输出非零中心

### Tanh
```python
def tanh(x):
    return np.tanh(x)
```
- 输出范围 (-1, 1)
- 零中心，但仍存在梯度饱和

### ReLU（最常用）
```python
def relu(x):
    return np.maximum(0, x)
```
- 计算简单，缓解梯度消失
- 缺点："神经元死亡"（负值梯度为0）

### Leaky ReLU
```python
def leaky_relu(x, alpha=0.01):
    return np.where(x > 0, x, alpha * x)
```

### Softmax（多分类输出层）
```python
def softmax(x):
    exp_x = np.exp(x - np.max(x, axis=-1, keepdims=True))
    return exp_x / np.sum(exp_x, axis=-1, keepdims=True)
```

## 损失函数

| 任务 | 损失函数 | 公式 |
|------|----------|------|
| 回归 | MSE | $\frac{1}{n}\sum(y-\hat{y})^2$ |
| 回归 | MAE | $\frac{1}{n}\sum\|y-\hat{y}\|$ |
| 二分类 | 二元交叉熵 | $-[y\log\hat{y}+(1-y)\log(1-\hat{y})]$ |
| 多分类 | 交叉熵 | $-\sum y_i\log\hat{y}_i$ |

## 选择指南

- 分类 → 交叉熵损失
- 回归 → MSE（无异常值）/ MAE（有异常值）
- 隐藏层 → ReLU（默认）
- 输出层 → Sigmoid（二分类）/ Softmax（多分类）/ Linear（回归）
