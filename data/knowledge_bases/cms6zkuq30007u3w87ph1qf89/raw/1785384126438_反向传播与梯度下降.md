# 反向传播与梯度下降

## 梯度下降

最小化损失函数的迭代优化算法。

```python
weights = weights - lr * gradient
```

### 三种变体

| 方法 | 每次使用数据量 | 特点 |
|------|---------------|------|
| BGD | 全部样本 | 准确但慢 |
| SGD | 1个样本 | 快但震荡 |
| Mini-batch | batch_size个 | 折中，最常用 |

## 反向传播（Backpropagation）

通过链式法则计算各层参数的梯度。

```
前向传播: X → 隐藏层 → 输出层 → loss
反向传播: loss → ∂loss/∂W₂ → ∂loss/∂W₁ → 更新参数
```

## 链式法则示例

```python
# 前向
z1 = W1 @ x + b1
a1 = relu(z1)
z2 = W2 @ a1 + b2
loss = mse(y, z2)

# 反向（伪代码）
dz2 = 2 * (z2 - y) / n        # ∂loss/∂z2
dW2 = dz2 @ a1.T               # ∂loss/∂W2
db2 = sum(dz2)                 # ∂loss/∂b2
da1 = W2.T @ dz2               # ∂loss/∂a1
dz1 = da1 * relu_derivative(a1)
dW1 = dz1 @ x.T
```

## 优化器

```python
# SGD（带动量）
optimizer = torch.optim.SGD(model.parameters(), lr=0.01, momentum=0.9)

# Adam（自适应学习率，最常用）
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

# RMSprop
optimizer = torch.optim.RMSprop(model.parameters(), lr=0.001)
```

## 学习率策略

| 策略 | 描述 |
|------|------|
| 固定学习率 | 简单但需手动调参 |
| 余弦退火 | 周期性调整 |
| ReduceLROnPlateau | 指标停滞时降低 |
| Warmup | 预热后逐步增大 |
