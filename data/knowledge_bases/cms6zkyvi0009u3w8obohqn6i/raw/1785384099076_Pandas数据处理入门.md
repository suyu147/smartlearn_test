# Pandas 数据处理入门

## Series 与 DataFrame

```python
import pandas as pd

# Series — 一维带标签数组
s = pd.Series([1, 2, 3], index=["a", "b", "c"])

# DataFrame — 二维表格
df = pd.DataFrame({
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, 30, 35],
    "city": ["北京", "上海", "深圳"]
})
```

## 数据查看

```python
df.head(10)          # 前10行
df.tail()            # 后5行
df.info()            # 基本信息
df.describe()        # 统计摘要
df.columns           # 列名
df.shape             # 形状

```

## 数据选择

```python
df["name"]                    # 单列
df[["name", "age"]]           # 多列
df.loc[0:5]                   # 标签索引
df.iloc[0:5, 0:2]             # 位置索引
df[df["age"] > 30]            # 条件筛选
df.query("age > 30 & city == '北京'")
```

## 数据清洗

```python
df.isnull().sum()             # 查看缺失值
df.dropna()                   # 删除缺失行
df.fillna(value)              # 填充缺失值
df.drop_duplicates()          # 去重
df.rename(columns={"old":"new"})
```

## 分组与聚合

```python
df.groupby("city")["age"].mean()
df.pivot_table(values="sales", index="city", columns="year")
```
