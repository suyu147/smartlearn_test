# 数据清洗与预处理

## 数据清洗流程

```
原始数据 → 缺失值处理 → 异常值处理 → 格式规范化 → 特征工程 → 清洗完毕
```

## 缺失值处理

```python
import pandas as pd
import numpy as np

# 检测
df.isnull().sum()
df.isnull().mean() * 100   # 缺失比例

# 删除
df.dropna(thresh=len(df) * 0.7)   # 删除缺失>30%的列
df.dropna(subset=["重要字段"])     # 关键字段缺失则删除行

# 填充
df.fillna(df.mean())              # 均值填充
df.fillna(df.median())            # 中位数填充
df.fillna(df.mode().iloc[0])      # 众数填充
df["col"].fillna(method="ffill")  # 前向填充
df["col"].interpolate()           # 插值填充
```

## 异常值处理

```python
# Z-Score 方法
from scipy import stats
z_scores = np.abs(stats.zscore(df_numeric))
df = df[(z_scores < 3).all(axis=1)]

# IQR 方法
Q1 = df["col"].quantile(0.25)
Q3 = df["col"].quantile(0.75)
IQR = Q3 - Q1
df = df[(df["col"] >= Q1 - 1.5*IQR) & (df["col"] <= Q3 + 1.5*IQR)]
```

## 数据转换

```python
# 类型转换
df["date"] = pd.to_datetime(df["date"])
df["price"] = df["price"].astype(float)

# 编码
pd.get_dummies(df["category"])                    # One-Hot 编码
from sklearn.preprocessing import LabelEncoder
df["label"] = LabelEncoder().fit_transform(df["label"])

# 归一化
from sklearn.preprocessing import MinMaxScaler, StandardScaler
MinMaxScaler().fit_transform(df[["col"]])         # [0,1]
StandardScaler().fit_transform(df[["col"]])       # 标准化
```
