# NumPy 数值计算基础

## 创建数组

```python
import numpy as np

arr = np.array([1, 2, 3])              # 一维
matrix = np.array([[1, 2], [3, 4]])    # 二维
zeros = np.zeros((3, 4))               # 全零
ones = np.ones((2, 3))                 # 全一
eye = np.eye(3)                        # 单位矩阵
arange = np.arange(0, 10, 2)           # [0, 2, 4, 6, 8]
linspace = np.linspace(0, 1, 5)        # [0, 0.25, 0.5, 0.75, 1]
random = np.random.randn(3, 3)         # 正态分布随机数
```

## 数组属性

```python
arr.shape      # 形状 (3, 4)
arr.dtype      # 数据类型 float64
arr.ndim       # 维度数
arr.size       # 元素总数
arr.T          # 转置
```

## 索引与切片

```python
arr[0]           # 第一行
arr[:, 1]        # 第二列
arr[1:3, :2]     # 子矩阵
arr[arr > 0]     # 布尔索引
arr[[0, 2]]      # 花式索引
```

## 运算

```python
arr + 1, arr * 2      # 广播运算
np.add(arr1, arr2)    # 加法
np.dot(a, b)          # 矩阵点乘
a @ b                 # @ 操作符（Python 3.5+）

np.sum(arr)           # 求和
np.mean(arr)          # 均值
np.std(arr)           # 标准差
np.max(arr)           # 最大值
np.argmax(arr)        # 最大值索引
```

## 广播机制

形状不同的数组运算时，NumPy 会自动扩展维度使形状兼容。

```python
a = np.ones((3, 4))
b = np.array([1, 2, 3, 4])
# a + b → b 广播为 (3, 4)
```

## 线性代数

```python
np.linalg.inv(a)         # 逆矩阵
np.linalg.det(a)         # 行列式
np.linalg.eig(a)         # 特征值/特征向量
np.linalg.svd(a)         # SVD 分解
```
