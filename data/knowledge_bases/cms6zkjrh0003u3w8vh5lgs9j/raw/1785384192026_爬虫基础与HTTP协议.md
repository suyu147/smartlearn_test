# 爬虫基础与 HTTP 协议

## HTTP 请求方法

| 方法 | 用途 |
|------|------|
| GET | 获取资源 |
| POST | 提交数据 |
| PUT | 更新资源 |
| DELETE | 删除资源 |

## 常见状态码

- **200** OK — 成功
- **301/302** — 重定向
- **403** — 禁止访问
- **404** — 未找到
- **500** — 服务器错误
- **502/503** — 网关/服务不可用

## 请求头（Headers）

```python
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ...",
    "Referer": "https://example.com",
    "Cookie": "session=abc123",
    "Authorization": "Bearer token"
}
```

## URL 结构

```
scheme://host:port/path?query#fragment
https://example.com:443/search?q=python&page=1#result
```

## 爬虫基本流程

1. **发送请求** — 获取 HTML/JSON
2. **解析内容** — 提取目标数据
3. **数据存储** — CSV/JSON/数据库
4. **异常处理** — 重试、日志

## Robots.txt

检查网站爬取规则：
```
https://example.com/robots.txt
```

## 注意事项

- 控制请求频率，避免对服务器造成压力
- 遵守网站的 robots.txt 和使用条款
- 注意数据版权和法律法规（如个人信息保护法）
