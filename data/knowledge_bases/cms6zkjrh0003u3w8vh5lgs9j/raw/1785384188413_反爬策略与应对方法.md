# 反爬策略与应对方法

## 常见反爬机制

### 1. User-Agent 检查
```python
headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) ..."}
```

### 2. IP 频率限制
```python
# 使用代理 IP 池
proxies = {"http": "http://proxy_ip:port", "https": "http://proxy_ip:port"}
resp = requests.get(url, proxies=proxies)

# 请求间隔
import time
time.sleep(random.uniform(1, 3))
```

### 3. Cookie/Session 验证
```python
session = requests.Session()
session.get(login_url, data=login_data)  # 先登录
resp = session.get(target_url)           # 获取数据
```

### 4. 验证码
- 图形验证码 → OCR（Tesseract、PaddleOCR）
- 滑块验证码 → 轨迹模拟（Selenium + ActionChains）
- 行为验证 → 第三方打码平台

### 5. JavaScript 渲染
- 分析 Ajax 接口直接请求
- 使用 Selenium/Playwright 渲染

### 6. 签名与加密
```python
# 分析前端加密逻辑，用 Python 实现
import hashlib
sign = hashlib.md5((param + secret_key).encode()).hexdigest()
```

## 反反爬原则

- **模拟真实用户** — 请求头、行为、时间间隔
- **分布式爬取** — 多 IP 分散请求
- **缓存** — 避免重复请求相同页面
- **Robots.txt 尊重** — 合规爬取
