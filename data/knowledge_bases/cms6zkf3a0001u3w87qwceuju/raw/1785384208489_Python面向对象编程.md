# Python 面向对象编程

## 类与对象

```python
class Dog:
    species = "Canine"  # 类变量

    def __init__(self, name, age):
        self.name = name    # 实例变量
        self.age = age

    def bark(self):
        print(f"{self.name} says Woof!")
```

## 三大特性

### 封装
- 使用 `_` 表示受保护成员，`__` 表示私有成员（名称修饰）

### 继承
```python
class Puppy(Dog):
    def __init__(self, name, age, toy):
        super().__init__(name, age)
        self.toy = toy
```

### 多态
- 不同类实现相同方法名，调用时表现不同行为

## 魔术方法

| 方法 | 用途 |
|------|------|
| `__init__` | 构造 |
| `__str__` | 字符串表示 |
| `__repr__` | 开发者表示 |
| `__len__` | len() |
| `__call__` | 对象可调用 |
| `__enter__/__exit__` | 上下文管理器 |

## 特性 property

```python
@property
def full_name(self):
    return f"{self.first} {self.last}"

@full_name.setter
def full_name(self, value):
    self.first, self.last = value.split()
```

## 抽象类

```python
from abc import ABC, abstractmethod

class Animal(ABC):
    @abstractmethod
    def sound(self):
        pass
```
