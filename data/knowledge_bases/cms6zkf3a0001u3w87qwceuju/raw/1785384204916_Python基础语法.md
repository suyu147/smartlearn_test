# Python 基础语法

## 变量与数据类型

- **数字类型**: `int`, `float`, `complex`
- **字符串**: 单引号/双引号，f-string 格式化 `f"Hello {name}"`
- **布尔型**: `True`, `False`
- **None**: 空值

## 容器类型

| 类型 | 可变 | 有序 | 示例 |
|------|------|------|------|
| list | ✅ | ✅ | `[1, 2, 3]` |
| tuple | ❌ | ✅ | `(1, 2, 3)` |
| dict | ✅ | ❌(3.7+有序) | `{"a": 1}` |
| set | ✅ | ❌ | `{1, 2, 3}` |

## 控制流

```python
# 条件
if x > 0:
    print("正数")
elif x == 0:
    print("零")
else:
    print("负数")

# 循环
for i in range(5):
    print(i)

while condition:
    pass
```

## 函数

```python
def add(a: int, b: int) -> int:
    return a + b
```

## 文件操作

```python
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()
```
